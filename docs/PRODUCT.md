# Product

## Purpose and audience

Choose Your Character is a short, browser-based personality-test experience for participants in a game-themed teaching assistant training event. It gives each participant a starter character or class based on how they respond to scenario questions.

The event story, wording, visual theme, and final character roster are still undecided. Initial content is intentionally brief and neutral so it can be replaced without redesigning the interface.

## Initial experience

1. The landing page introduces the activity and starts a new session.
2. The adventure presents exactly eight ordered questions, one at a time.
3. The participant selects an answer before advancing.
4. Completing the final question calculates one of three character results.
5. The result page explains the match and offers a way to restart.

A direct visit to the result page without a completed session must return the participant to a safe starting point or clearly offer a restart.

## Initial requirements

- Keep question and character content separate from presentation code.
- Produce the same result for the same answers and configuration.
- Support keyboard use, visible focus states, semantic controls, and mobile and desktop layouts.
- Keep the interface visually neutral and easy to reskin.
- Avoid back-end services, accounts, persistence, analytics, and branching narrative until they are demonstrated requirements.
